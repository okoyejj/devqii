How to replace remote images before production deployment:
1. Download the preferred images and save them in assets/images/.
2. Rename them to descriptive filenames such as hero-students.webp, computer-lab.webp and teamwork.webp.
3. Update the src values in the PHP/HTML pages to point to the local files.
4. Keep this file updated with the final image sources and licenses.
